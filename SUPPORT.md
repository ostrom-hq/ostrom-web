# Getting help

| You want to                                         | Go to                                                                                                    |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Learn how Ostrom works                              | [the documentation](https://ostrom.run/docs)                                                             |
| Ask a question, share an idea                       | [GitHub Discussions](https://github.com/ostrom-hq/ostrom-web/discussions)                                |
| Report a bug                                        | [a new issue](https://github.com/ostrom-hq/ostrom-web/issues/new/choose), with the steps to reproduce it |
| Report a vulnerability                              | **privately**, as described in [SECURITY.md](SECURITY.md)                                                |
| Talk about a plan, a pilot or self-hosting at scale | [hello@ostrom.run](mailto:hello@ostrom.run)                                                              |

Ostrom Cloud customers on a paid plan get support from the team directly, in the console.

Please search existing issues and discussions before opening a new one, and keep one topic per thread.
